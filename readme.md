## 京东互动游戏 jdig 重构（`modules/jd_interactive_games.js`）

- 进入流程重写：启动京东 → 我的 → 互动游戏，每步都带等待与页面校验；冷启动 `launchApp` 不生效时回退到直接拉起主 Activity。
- 攒经验任务：
  - 进入游戏页"赚京豆"区的"攒经验"弹窗，每轮从当前界面重新选取一个未处理过的可见"逛一逛"按钮，不滚动、不处理屏幕外按钮。
  - 点击任务后 15 秒内每 500ms 检查一次"点击立即返回"，出现即点击返回；超时则按 `doubleBackN(1)` 连续两次返回。

- 返回主界面：识别"我的"页切首页 tab，逐层返回失败时重新拉起主 Activity 兜底；小游戏拦截返回键也能恢复。
- 日志统一使用 `lib/logger`：过程信息用 `debug`，仅任务结束时用一次 `info`（成功/失败）提示。
