# 找不同工具：算法原理与已验证的失效模式

## 算法流水线（spot_diff.py）

1. **版面切分**：整图自差曲线 `mean|g[:H-dy] - g[dy:]|` 的最小值对应面板周期（上下两幅内容重复），再滑窗找起点；横竖两个方向各算一次，按自相似残差选优。**不要**用梯度峰法——边框对比度低时会只找到半个面板，把图横切错。
2. **配准**：8x → 4x → 2x → 1x 分层搜索全局偏移，降采样必须用**块平均**（隔行抽样会混叠，导致配准错位）。
3. **色差**：Lab 空间 ΔE，而不是灰度。灰度丢失色相，纯颜色替换（罐子粉→黄、纽扣绿→红、玻璃蓝→黄灯）会全部漏掉。
4. **抗错位**：每像素取 3×3 邻域 9 个位移下的**最小** ΔE。渲染亚像素错位产生的细线假阳性会因此消失（未加此步时曾出现 116 个碎块）。
5. **组件筛选**：`diff > thr` → 开运算去细线 → 闭运算 → 删除全宽/全高细条纹（见坑 4）→ 膨胀聚合 → 连通域 → 填洞 → 面积/边长/填充率筛选 → 强信号救援（见坑 3）→ 同物体碎片合并（默认不按距离合并，`join_px=0`）。

## 已验证的失效模式

### 坑 1：灰度比对丢颜色差异

- 现象：颜色替换类差异全部漏检。
- 修法：改用 Lab ΔE。**不要**退回灰度。

### 坑 2：块内均值池化稀释小目标

- 现象：最小差异可能只有 8×7 像素（耳环），分块求均值后低于任何合理阈值。
- 修法：逐像素算 ΔE，块聚合只用于**定位热点**，不用于判定。可选：先 16px 网格降到 10x 分辨率找热点区域，再回原分辨率精算。

### 坑 3：弱对比物体被填充率过滤（白枕贴白帘）

- 现象：多出来的白枕头贴着白门帘，内部 ΔE 极低，掩码只剩轮廓散点，bbox 填充率 0.20 < `min_fill` 0.30 → 被当噪声删掉。闭运算、填洞、降阈值（到 8 也只有 0.41）都救不回来。
- 修法：**强信号救援**——填充率不足但差异能量足够强的组件照样保留，条件为 `200 ≤ area ≤ 8000` 且 `w,h ≤ 150` 且 `fill ≥ 0.12` 且 `mean_ΔE ≥ 25` 且 `max_ΔE ≥ 40`。尺寸上限必须有，否则全图散布的渲染噪声场会被救进来，合并成一个全屏大框。

### 坑 4：接缝伪影"连坐"误杀邻近真差异（叶片漏检）

- 现象：植物叶片差异紧贴面板底边，离全宽接缝伪影只有 5px；连通域在**膨胀后**的掩码上标记，两者连成一体，合并组件横跨全宽 → 触发接缝过滤器，真差异跟着被整组删掉。
- 修法：**连通域分析前**直接从掩码删除全宽/全高细条纹（覆盖率 > 0.80 且连续厚度 ≤ 20px 的带，横竖两个方向各清一次），不要留到组件阶段事后过滤。

### 坑 5：过度合并 / 过度拆分

- 现象 A：近距离差异链式合并成一个全屏大框。→ `join_px=0`，不按距离合并。
- 现象 B：同一个物体（如一只花盆白→蓝）被判成两个框。→ 报点时按"同一物体"人工合并。
- 现象 C：一个框里其实是两处独立差异（仙人掌形态 + 椅边书画）。→ 框数对不上"？"数时，用更低阈值或局部小区域重新分簇，检查框内是否有多个分离簇。

## 坐标与调试

- `_diffs.json`：`info.top` / `info.bottom` 是两幅面板的行区间，`offset` 是配准偏移，(dy, dx)。
- **bbox 是面板相对坐标**，绝对 y = `bbox_y + info.top[0]`。
- 垂直偏移通常 727 或 728，同一关内恒定；局部残差为 0 说明没有缩放差异。
- 竖直线状差异（如 x=235 处贯穿全高的一条线）是渲染亚像素噪声，不是真差异——用模板匹配验证：拿一个特征物体在上图取模板，到下图搜索最佳匹配，得到的偏移与全局一致即可确认。
