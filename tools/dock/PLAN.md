# 接驳位解锁辅助（tools/dock）

> 状态：**已实机跑通**（2026-11-27，小米 2209129SC / 1080×2400）。
> 已验证关卡：第89关（解锁 2 个，另 1 个已解）、第90关（解锁 3 个，全清）。
> 目标：把对局顶部带「解锁」按钮的接驳位全部解锁（看广告），其余操作交还用户。

## 一、游戏事实（实机确认）

| 项 | 结论 |
| --- | --- |
| 槽位行 | 画面中部、灰色分隔条之上，一排约 7 个 rounded 虚线位 |
| 未解锁位 | 紫色圆角按钮，内含白色螺丝图标 + **橙色螺丝头**，竖排「解锁」文字 |
| 已解锁位 | 淡紫底虚线空位，无按钮 |
| 点「解锁」 | 直接跳到京东广告落地页（`优选好物立即抢`），部分场次先弹「获得福利」 |
| 获得福利弹窗 | 橙色丝带标题 + 黄色「领取（视频）」按钮 + 右上角蓝色 X。**关 X 不涨进度**，只是取消 |
| 广告返回 | 落地页右上角红袋「已完成 / 点击立即返回」；控件树有 `text="点击立即返回"`，按返回键也能退出 |
| 解锁结果 | 回到对局后该位变虚线空位，按钮少一个（实测 3 个→2 个→1 个→0 个） |
| 控件树 | 游戏本体是 canvas，dump 无文字节点；广告页有文字节点 → 可复用 `common/adb.find_text_node` |

## 二、识别方案（templates/ 4 个模板 + 1 条颜色规则）

1. **解锁按钮 = 螺丝图标**（`dock_vision.detect_unlock_buttons`）
   - 只在槽位横条 ROI（`y ∈ 0.33H~0.50H`，整幅宽）内找高饱和橙色连通域；
   - 面积 150~900、边长 13~36、方形度 ≥0.45 先做粗筛；
   - **两层环形校验**（关键）：螺丝图标是「白色圆角方块(~60px) + 橙色螺丝头(~22px)」，
     - r13~20px 已完全落在白块里 → 白 ≥0.85、橙 ≤0.05；
     - r21~30px 仍是白块或其外灰紫按钮底 → 橙 ≤0.10、白 ≥0.55。
   - 为什么必须做：车顶上印着**同尺寸的橙色小圆点**（实测面积/边长与螺丝头完全一致，
     inner white 甚至能到 0.87），只有「外圈几乎没有橙色」这条能把它们分开。
     实测第89/90关 3 个按钮全命中、7 个已解码位 + 车顶圆点 0 误报。
2. **福利弹窗**：`claim.png`（黄色领取按钮）模板匹配 → 命中即判定弹窗，不再点按钮。
3. **弹窗关闭**：`close_x.png`（蓝色 X）模板，ROI 右上区域。
4. **是否在对局**：`game_mark.png`（底部「刷新」按钮）+ **亮度校验**。
   - 弹窗会给整屏盖半透明黑幕，TM_CCOEFF_NORMED 对整体压暗不敏感（暗化后仍能得 1.0），
     所以额外要求命中块平均亮度 ≥ 模板亮度 ×0.75，避免把「弹窗下的对局」误判成已回对局。
5. **广告落地页返回**：先找 `return_tag.png`（红袋按钮），找不到再 dump 控件树找「点击立即返回」，
   最后按返回键（`--max-back`）。

## 三、自动流程（dock_auto.py）

```
抓图 → 有弹窗? 点 X 关掉
     → 不在对局? return_to_game()（等广告 → 找返回 → back）
     → 找解锁按钮，没有则结束
     → 点最左一个 → 轮询 12s：弹窗关 X / 广告页等返回 / 回对局
     → 回对局后按钮数减少即成功，否则重试（连续 3 次失败停手）
```

- 按用户口径：**福利弹窗一律点 X**，不点「领取」；`--claim` 可显式改成点领取（仅调试用）。
- `--ad-wait`（默认 16s）先等落地页倒计时，避免过早点击被判定未完成。

## 四、参数

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| `--once` | - | 只识别一次，输出 `outputs/dock_annotated.png` |
| `--dry-run` | off | 只打印要点的坐标，不点击、不通知 |
| `--max-unlock` | 6 | 本轮最多解锁几个 |
| `--max-seconds` | 420 | 总超时 |
| `--ad-wait` | 16 | 点完解锁后先等多久 |
| `--ad-timeout` | 50 | 等广告结束总超时 |
| `--max-back` | 3 | 广告页最多按几次返回 |
| `--claim` | off | 弹窗改点「领取(视频)」 |
| `--max-fails` | 3 | 连续失败上限 |
| `--no-notify` | - | 关状态栏通知 |

## 五、已知限制

- 槽位横条 ROI 按本关比例写死（`0.33~0.50`）。若某关槽位明显更高/更低，需调 `SLOT_BAND`。
- 广告形态可能变（视频贴片 / 小程序页）；目前靠「红袋返回按钮 → 文字节点 → 返回键」三级兜底，
  真遇到无法退出的广告需人工介入。
- 解锁次数由游戏投放决定；`--max-unlock` 只做上限保护。
- 仅模拟点击，不改游戏数据、不绕过付费。
